# 4K Monitor Value Frontier

**Live page:** https://lhjelm-dk.github.io/monitor-frontier/

Idea by **Mark Ruvald Pedersen**.

An interactive comparison of 4K and higher-resolution monitors from 24″ to 52″ that are sold in Denmark. Each monitor gets a combined rating from RTINGS.com and other review sites, and is priced at the cheapest Danish shop (PriceRunner.dk and CS MEGASTORE, shipping included). The page shows the price–rating Pareto frontier, a best-value pick with how robust it is, and lets you filter by size, panel, brand, price, refresh rate and USB-C features.

This public version shows only the combined rating. Individual review scores are not republished; the page links to each review instead.

The page is a single static HTML file (`index.html`), rebuilt and pushed automatically every morning. Prices change constantly, so check the shop before buying. Not affiliated with RTINGS, PriceRunner or any shop or manufacturer.
